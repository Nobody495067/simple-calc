Background

Choose the appearance used by the game library.

Image-to-animation background

Upload one still image (PNG, JPG, or WebP). The library animates it with moving waves, depth, and floating particles. This is not a video uploader: animated GIFs are treated as a still image. Your image stays in this browser and is not uploaded to a server. After saving, click Apply Animated Wallpaper above, then return to the library.

Theme accents

Choose an accent color for the library. Your existing background and wallpaper settings remain available above.

Save states & game saves

Use EmulatorJS's built-in Save State and Load State controls in the player toolbar while a game is running. Save states can be downloaded and loaded again later; availability depends on the selected console core.

Controller & keyboard mapping

Set Player 1 keyboard keys here. These are applied when a game starts. For a connected gamepad, open the EmulatorJS toolbar and choose Controls to configure its buttons.

Audio

Choose the starting volume for games. This is applied when the emulator launches.

Privacy & shortcuts

Click a field and press the key you want to assign. Shortcuts are active while the library is open, except when typing in a text field.
